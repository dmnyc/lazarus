# Logo

The Lazarus wordmark, for implementations that want to show it. Totally
optional: using it — or not — has no bearing on conformance or on being
listed in the README's implementations table.

- `lazarus-wordmark-{black,grey,white}.svg` — vector source, one flat fill
  color each; recolor or scale freely.
- `png/` — transparent-background PNGs in the same three colors, 1461×359
  and @2x 2922×718, ready to drop into an app.

Guidance: black or grey on light backgrounds, white or grey on dark. The
wordmark is wide (about 4:1); keep the aspect ratio when scaling.
